# Coding Agents Statuslines

A collection of polished, high-density statuslines for AI coding assistants and CLI agents.

## Supported Agents

- **[Antigravity CLI (`agy`)](./antigravity-cli)**: 4-line statusline featuring model, effort, user, device, git branch, 1M context bar, session timer, cost, and 5h/weekly quota meters.

## Contributing

Pull requests adding support or presets for other coding agent CLIs are welcome!
